1. Extract findjob folder to ~/projects/
2. Create postgres database:
   CREATE DATABASE findjob;
3. Edit application.properties with your DB credentials
4. Build project:
   mvn clean install
5. Run application:
   mvn spring-boot:run
6. Access at: http://localhost:8080
